# Reports and Evidence

Generated reports and figures belong here.

- `report.md` — report structure mapped to the nine assignment tasks.
- `architecture.md` — architecture diagram and explanation.
- `figures/` — generated EDA and model-evaluation figures.
- `model_comparison.csv` — CV/test comparison generated by training.
- `cv_results_<model>.csv` — complete grid-search results for each model family.

Before final submission, replace the report placeholders with the actual results from your run and add the required screenshots to `screenshots/`.
